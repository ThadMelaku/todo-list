# Todo List

A todo list application built as part of The Odin Project.

## Features

- Multi-project task management system
- Full CRUD functionality for todos
- Expandable task details with inline editing
- Due date formatting using date-fns
- Persistent application state using localStorage and JSON serialization
- Dynamic DOM rendering and event-driven UI updates

## Built With

- JavaScript (ES6 Modules)
- HTML/CSS
- Webpack
